# Mathematical Computing with Python

Welcome to the course site! This book collects the lecture notebooks used in
class, in order, so you can follow along, review material after class, and
run the code yourself.

## How to use this site

- Each chapter in the left sidebar corresponds to one class session.
- Every page is a live Jupyter notebook, you can read the rendered output
  here, or click the rocket icon at the top of a page to launch it in
  **Google Colab** and run the code interactively.
- Code cells show both the code and its output, so the site works even if
  you don't run anything yourself.
