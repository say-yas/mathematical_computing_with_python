1. Variables and Data Types#

Python is dynamically typed: a variable’s type is determined by the value assigned to it, and can change if you reassign it.

3. Control Flow: if, for, while#

General forms#

if / elif / else

if condition1:
    # runs if condition1 is True
elif condition2:
    # runs if condition1 is False and condition2 is True
else:
    # runs if none of the above are True

elif and else are both optional, and you can chain as many elifs as you need.

for loop

for item in iterable:
    # runs once per item in iterable (a list, string, range, etc.)

while loop

while condition:
    # runs repeatedly as long as condition is True
    # something inside the loop must eventually make condition False

score = 74

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"A score of {score} earns a grade of {grade}")

A score of 74 earns a grade of C

# for loop over a list
for s in scores_list:
    status = "pass" if s >= 70 else "fail"

4. Functions#

Functions let us package logic for reuse. This is essential once our mathematical computations get more involved.

General form#

def function_name(parameter1, parameter2, ...):
    """Optional docstring describing what the function does."""
    # body: do something with the parameters
    return result  # optional; omit if the function has no output

  • parameter1, parameter2, ... are placeholders filled in each time the function is called.

  • return sends a value back to wherever the function was called; a function with no return implicitly returns None.

  • Parameters can have default values: def f(x, y=0): makes y optional when calling f.

def average(numbers):
    """Return the arithmetic mean of a list of numbers."""
    return sum(numbers) / len(numbers)

def letter_grade(score):
    """Convert a numeric score to a letter grade."""
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "F"

print("Average score:", average(scores_list))
print("Letter grades:", [letter_grade(s) for s in scores_list])  # list comprehension

Average score: 82.0
Letter grades: ['B', 'A', 'C', 'A', 'F', 'C', 'B']

A quick note on list comprehensions#

[letter_grade(s) for s in scores_list] is shorthand for:

result = []
for s in scores_list:
    result.append(letter_grade(s))

You’ll see this compact style constantly in mathematical/scientific Python code.

5. Introducing NumPy#

Importing a package#

Before using NumPy, you need to import it. The standard convention is:

import numpy as np

  • import numpy brings in the package under its full name.

  • as np gives it a shorter alias, so you write np.array(...) instead of numpy.array(...) everywhere. This is the convention essentially everyone uses for NumPy.

  • You only need to do this once per notebook or script, at the top, before any code that uses np.

Plain Python lists are flexible but slow for numerical work, and they don’t support element-wise math out of the box. NumPy gives us the ndarray object: a fast, fixed-type, multi-dimensional array with vectorized operations.

Let’s rebuild our gradebook example as a small dataset and explore it with NumPy.

import numpy as np

np.random.seed(42)  # reproducibility: everyone gets the same "random" data

# Simulate a small dataset: exam scores for 30 students across 3 exams
n_students = 30
exam1 = np.random.normal(loc=75, scale=10, size=n_students).round(1)
exam2 = np.random.normal(loc=78, scale=8, size=n_students).round(1)
exam3 = np.random.normal(loc=82, scale=9, size=n_students).round(1)

# Clip so nobody scores above 100 or below 0
exam1, exam2, exam3 = (np.clip(e, 0, 100) for e in (exam1, exam2, exam3))

# Stack into one 2D array: rows = students, columns = exams
gradebook = np.column_stack([exam1, exam2, exam3])

print("Shape (students, exams):", gradebook.shape)
print(gradebook[:5])  # first 5 students

 [90.2 69.5 71.2]

Notice gradebook is a single NumPy array containing everyone’s scores. Unlike the plain Python list from Section 2, this is a genuine dataset: rows are observations (students), columns are variables (exams) — a layout you’ll see constantly in mathematical computing and data analysis.
